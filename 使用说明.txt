枫叶单词 v1.2.1

1. 请先解压整个文件夹，不要直接在压缩包内运行。
2. 双击“启动枫叶单词.cmd”，浏览器会自动打开学习页面。
3. 保持启动窗口运行。结束学习后关闭窗口即可停止服务。

完整 Windows x64 包已包含 Node.js 和 SQLite 依赖，无需安装 Node 或执行 npm install。
词库、释义、例句、搜索、练习和进度保存在本机。朗读取决于 Windows / 浏览器是否已安装英语语音。

默认地址：http://127.0.0.1:5173/
六级核心词书：2078 个不重复单词，42 个单元。
词书管理可导入导出 JSON 词书；我的笔记可筛选星标、不认识、模糊并进入复习。

备份或升级：先停止服务，再复制完整 data 文件夹。请保留旧版，不要直接覆盖 data/state.json。
发布包使用空白学习记录。升级时先把旧 data 完整复制到新版本目录再启动。
未登录时，连接同一个本地服务的所有浏览器共用进度，已有页面需刷新查看更新。
首次启动自动将旧浏览器匿名记录备份到 data/backups，再去重合并已学单词和保留重点标记。
注册账户仍各自独立；另一浏览器需登录同一账户。不同电脑或不同软件副本的数据各自保存。
完整功能、快捷键、数据来源与已知限制请阅读 README.md 和 THIRD_PARTY_NOTICES.md。
